四种靠近她的方式

不改她的底色，只换她坐到你面前的方式。四案都以现有雾蓝清透为基准：同样的墨青、青绿、圆角与细边框，只在信息层级、空间结构和时间感上分叉。

雾纸 #EAF3F8 墨青 #1E3A46 青绿 #2E7D73 细边 1px

基准保留：14px 圆角、3px 侧边气泡线、圆形头像、轻阴影、短句节奏。四案不引入新的视觉语言，只重新分配注意力。

阶段二附带 · 人格化结构优化

Based on DeepSeek Literature Review
P0 · episode → memory 巩固

高情绪峰值或高重复的聊天片段自动提升为长期记忆；低显著性不删除，只在召回中降权。

P1 · somatic_charge 体感标记

写入时记录情感电荷，召回时作为第三项弱信号（0.08–0.12），让“很重的事”更容易被想起。

P1 · 车道预埋

给前台聊天、人格化、后台任务打 lane 标签；当前行为不变，先获得可观测的排队与耗时。
