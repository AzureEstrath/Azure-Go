## 一、意图与为什么

**现状（实测本机 v3.3.0 代码）**：

| 现象 | 事实 |
| --- | --- |
| 提示词里**没有玩家画像** | `SYSTEM_PROMPT` 里「棋力碾压级别」说的是 **Azure 自己**；`【当前用户是 Estarth（你的部署者）】` 是**固定文案**、不含数据；`context_block` 的 7 个区块**没有一格是画像** |
| 只有一个「像记忆的东西」 | 长期记忆（`long_term_note`）存的是**每局总结 + 结果**的自由文本，**默认关闭**，**结构化程度为零** |
| 她**不知道时间** | 全仓没有任何时间上下文注入；她不知道现在几点、这局下了多久、你多久没来 |

想要的是：**她心里有你这个人**（开局偏好、行棋风格、常犯的错、喜欢聊什么），并且**知道时间**（现在几点、这局多久、距上次几天、连续第几天）。

## 二、目标（用户已拍板）

1. **对局记录**：**手动结束对局**后落一条**结构化记录**（时刻 / 手数 / 结果 / 胜率·目差 / 双方失误 / 进入的定式族 / 聊天主题 / 每手用时）。
2. **棋风画像**（独立 **`profile.db`**）：由记录**指数衰减增量**融合而成，**四个维度全要**：
   - **开局偏好**：星位 / 小目 / 三三 / 目外占比、常用挂角守角（与 v3.6 定式族计数天然联动）；
   - **行棋风格**：激进 ↔ 稳健（战斗 / 打入 / 断 / 脱先 / 围空频率）；
   - **失误与薄弱方位**：常亏手型（深入 / 无理 / 方向 / 随手）+ 四个角·边的薄弱方位；
   - **性格与话题**：聊天主题偏好、称呼与语气偏好。
3. **画像注入提示词**：新增**画像区块**，插在**铁律段之前**；**空串不留痕**（逐字符不变）。
4. **时间感知**（四项全要）：
   - **当前时间 / 星期**；**本局时长与单手用时**；**距上次对局的间隔**；**连续下棋天数**。
5. **三个延伸方向**（用户已选）：
   - **主动约战 / 提醒**（隔几天没下，她主动打个招呼邀请）；
   - **画像可视化面板**（界面里能看「她眼中的你」）；
   - **局末进步报告**（每局结束对比上一版画像，说清这局进步在哪）。

**明确未选**（留在候选池，本轮不做）：**玩家手动修正 / 清空画像**。

## 三、非目标 / 反目标

- **不许她变话多**：时间与画像**只在相关时提**；**禁止每句念时间/数字**（守项目既有反目标）。
- **不许回合内加调用**：写入与融合**只在 `summarize()`（手动结束）里做**，落子回合内**零新增 LLM / 引擎调用**。
- **不许把棋盘弄坏**：画像 / 时间故障**只打日志**，绝不影响对局；`busy` 必归位。
- **不许改既有语义**：铁律段、既有 7 个区块、`context_block` 的空串逐字符不变、`MAX_LLM_CALLS_PER_TURN`、音画同步——**一行不动**。

## 四、性能与可靠性红线（第一位）

| 红线 | 做法 |
| --- | --- |
| **写入时机** | 只在 `summarize()`（手动结束）内；**不新增回合内调用** |
| **异步纪律** | 所有 SQLite / 磁盘调用一律 `await asyncio.to_thread(...)`（**不得**直接放进 `async def`） |
| **故障降级** | 库被删 / 只读 / 目录不存在 → **当成「无画像」**，照常下完、照常总结；`busy` 归位 |
| **提示词有界** | 画像块 + 时间块都有**字符预算**（建议与 `memory_max_inject_chars` 同量级，默认 240）；超限丢最低置信 / 最旧维度 |
| **golden 锁定** | 画像块 / 时间块**为空 → 输出逐字符不变**（`tests/golden/prompts.json`） |
| **不新增 LLM 调用** | 「进步报告」**并进现有 `summarize()` 的提示词**，不额外调一次模型 |

## 五、我替用户拍的（可推翻，标出来只为让你一眼看到）

| # | 决定 | 理由 |
| --- | --- | --- |
| A | 融合用**指数衰减 EMA**：`v ← v*(1-α) + x*α`；α 由「半衰期 N 局（默认 20）」与「该维已有样本数」算出，**单局 α 有上限**（默认 0.25） | 「微增量」的字面实现；防一局爆冷改写画像 |
| B | **记录与画像分两张表**：`games`（一局一行，只增不减）/ `profile`（每维一行：值 + 置信度 + 更新时刻） | 记录可追溯（O20），画像可随时重建 |
| C | 每个数值维度**归一化到 `[0,1]`**，并**附带一句自然语言摘要**（给模型看的那句由模板拼，不由模型生成） | 省 token、可测、不引入 LLM 调用 |
| D | 时间事实**与画像同块注入**（时间在上、画像在下），**都插在铁律段之前** | 少一处插入点、少一类回归 |
| E | 主动约战**只在「玩家连上 / 首次交互」时触发一次**，由后端决定、前端只显示；**不主动推消息** | 不做「定时骚扰」；也算守住反目标 |
| F | 画像面板 = **只读** `GET /api/profile`（返回各维 + 来源局）+ 前端一格（沿用设置抽屉那套） | 只读、无副作用 |
| G | 进步报告**并进 `summarize()` 的现有提示词**（多给模型「上一版画像 + 本局记录」素材），**不新增调用** | 守 `MAX_LLM_CALLS_PER_TURN` 与性能红线 |
| H | 单手用时：后端**在 `POST /api/move` 到达时记时间戳**、下一手到达时结算；**不要求前端配合** | 零前端改动，采集天然 |
| I | 新一轮评估里 **`profile.db` 与 `memory.db` 不互相依赖**（memory 关闭时画像照常工作） | 两个功能解耦 |

## 六、接口草图（够你规划，不构成实现约束）

### 6.1 表结构（`backend/data/profile.db`，已 gitignore）

```sql
CREATE TABLE IF NOT EXISTS games(
  id INTEGER PRIMARY KEY, ts REAL,            -- 结束时刻（墙钟）
  move_count INTEGER, final_black_wr REAL, final_score REAL,
  result TEXT,                                -- 一行文字结果
  moves TEXT, per_move_ms TEXT,               -- JSON
  joseki_families TEXT, chat_topics TEXT,     -- JSON
  summary TEXT);

CREATE TABLE IF NOT EXISTS profile(
  axis TEXT PRIMARY KEY,                      -- 见 6.2 的维度键
  value REAL, confidence REAL,                -- [0,1]
  n_games INTEGER, updated_ts REAL);
```

### 6.2 画像维度键（四组）

- 开局偏好：`open.star` / `open.komoku` / `open.sansan` / `open.mokuhazushi` / `open.favorite_kakari`
- 行棋风格：`style.aggression` / `style.tenuki` / `style.territory_vs_influence`
- 失误与方位：`blunder.rate` / `blunder.top_type` / `weak.corner_tl|tr|bl|br`
- 性格与话题：`persona.topic.*` / `persona.address_pref`

### 6.3 提示词区块（插在**铁律段之前**）

```python
# backend/app/prompts.py
def profile_note(profile: dict, now_move_no: int, max_chars: int = PROFILE_MAX_CHARS) -> str
def time_note(t: dict, max_chars: int = TIME_MAX_CHARS) -> str
```

- 两者**为空 → 返回 `''`**（逐字符不变）。
- `time_note` 渲染例子：`【时间事实 · 供你自然提及，不必每句都说】现在是 {日期} {星期} {时刻}；本局已下 {h 时 m 分}，你平均每手 {s} 秒；距上次对局 {d} 天；连续第 {n} 天在陪 Estarth。`
- **硬规则**：时间与画像**只在相关时提**；**禁止把数字当口头禅复述**（写进块内的说明句 + AGENTS 硬规则）。

### 6.4 端点

| 端点 | 说明 |
| --- | --- |
| `GET /api/profile` | **只读**：返回各维值 + 置信度 + 来源局（面板用） |
| `POST /api/config` | 新增 `profile_enabled`(bool)、`time_aware_enabled`(bool) 透传 |

## 七、门卫

- **后端**（标准库 `unittest`，不得引入 pytest）：
  - `profile_store`：库被删 / 只读 / 目录不存在 → **降级为「无画像」**、不抛；`games` 只增不减。
  - 融合：EMA 正确性；**单局 α 上限**；半衰期；置信度随局数上升。
  - 画像块 / 时间块：**空 → 逐字符不变**（`golden/prompts.json` 仍绿）；超预算按「最低置信 / 最旧」丢。
  - 时间：单手用时结算（首手无前一手 → 不计）；`距上次对局` / `连续天数` 的跨日与跨时区边界。
  - 主动约战：**只在连接/首次交互触发一次**、且**不新增 LLM 调用**（假 LLM 断言调用数）。
  - 进步报告：**并进 `summarize()`**，LLM 调用数**与改动前一致**。
- **前端**（Godot headless）：`test_config.gd` 保持 24/24（新增两个开关字段的读写 + 未知键保留）。
- **既有门卫必须继续全绿**：后端全量 + `katago_service` 全量 + `test_config.gd` / `test_tts.gd` / `test_speech_pairing.gd`。
